The sample photograph is the existing public Rumi Guitars Martinez MF-17
product photo, copied from the previously downloaded website-gallery reference:
https://rumiguitars.com/product/martinez-mf-17-flamenco-guitar/

The Admin gallery uses this photograph to compare layout and lettering. It does
not generate a replacement product image or modify customer campaigns.

The branded gallery also embeds the original Rumi Guitars website logo, unchanged:
https://rumiguitars.com/wp-content/uploads/2026/06/cropped-Rumi-guitars-logo-1-3.png
The source site's custom-logo markup identifies this asset. It is placed with `meet`
to retain its original aspect ratio. A different brand name removes this sample
logo until the administrator supplies the correct logo.

Typography is embedded into each SVG and the resulting PNG, so exported lettering
matches the preview on another device. Fonts are licensed under the SIL OFL:
- Barlow Condensed ExtraBold (`display.woff2`), Google Fonts;
  license: `BarlowCondensed-OFL.txt`.
- Cormorant Garamond Semibold, regular and italic (`editorial.woff2`,
  `editorial-italic.woff2`), Google Fonts; license: `../fonts/CormorantGaramond-OFL.txt`.
- Existing Noto Sans Latin regular (`../fonts/noto-sans-latin-400-normal.woff`).

These are proposed design treatments, not claims that these fonts are the brand's
own official fonts. The website logo and product photograph retain their original
pixels. Curves, color fields, typography and frames are separate SVG elements.
